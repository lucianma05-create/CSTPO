# 主对比实验

口径：两组在完全相同条件下运行——同一 300 case 冻结评估集（t001–t100 × 3 任务）、同一 Cog-Sim 用户模拟、同一 judge rev4（n=3）、同一自由交互协议（13 轮起判冗余、30 轮上限）、同一后处理。唯一区别：策略骨干。gpt-5.5 组走 happy API（temperature 0 硬编码）；Qwen3-14B 组走本地 vLLM（GPU1、128 并发、enable_thinking=False）。统计 = 按 case 聚类 cluster bootstrap（2000 次，* = p<0.05）。成对 diff 分两层：方法 − standard（同骨干内），Qwen3-14B （同方法跨骨干，逐 case 配对）。加粗 = 该行/该骨干最优值。

## 方法清单（论文来源与做法）

| 方法 | 论文 | 做法 |
|---|---|---|
| standard | PPDPP（Deng et al., ICLR 2024）Table 8；TRIP（Zhang et al., EMNLP 2024）Table 20；ESConv-SRA（arXiv:2402.10453）template6 | 任务角色提示 + 完整对话历史直接生成下一句，无任何策略注入 |
| proactive | "Prompting and Evaluating Large Language Models for Proactive Dialogues: Clarification, Target-guided, and Non-collaboration"（Deng et al., Findings of EMNLP 2023） | 先让模型从任务策略词表选一个策略 a，再按其生成回应 r |
| procot | 同上（Deng et al. 2023a） | 在选策略前先产生"当前进展分析 + 目标"思考段 t：t→a→r 三步链 |
| ane | "Ask an Expert: Leveraging Language Models to Improve Strategic Reasoning in Goal-Oriented Dialogue Models"（Q. Zhang et al., Findings of ACL 2023） | 先写领域专家对最佳下一步的建议，再按建议生成回应 |
| mi_prompt | "Controllable Mixed-Initiative Dialogue Generation through Prompting"（Chen et al., ACL 2023 Short） | 选中的策略标签先翻译成自然语言指令，再按该指令生成回应（标签→指令映射链） |
| ppdpp | "Plug-and-Play Policy Planner for Large Language Model Powered Dialogue Agents"（Deng et al., ICLR 2024） | 冻结 LLM 生成话语 + roberta-large 策略 planner（SFT + RL 两阶段训练）；planner 从手工策略集选动作标签填入提示 [action] 槽 |
| dialogxpert | "DialogXpert: Driving Intelligent and Emotion-Aware Conversations"（Rakib et al., AAAI 2026） | 每轮 LLM 采样 4 条候选话语并推断用户情绪；冻结 BERT 编码"状态+候选"，小 Q 网络（768→64→64→1）学价值、选 Q 最大者（DQN，终局回报监督） |
| cstpo-sft / cstpo-rl | 本项目 | 14B 蒸馏 SFT（模仿高性能行为轨迹 + 真实数据混合训练）；RL = 蒸馏 SFT + 认知 critic（V/U 双头）PPO，策略字段与话语字段分别用策略优势与话语优势更新 |

注：proactive/procot/ane/mi_prompt 只把最终回应段送入对话（原仓库把完整 CoT 输出当回复），提取规则与适配偏差见 baseline/README.md。
