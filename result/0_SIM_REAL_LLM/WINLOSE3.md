# 三维修度 win/lose 盲评存档（2026-09-22）

基于剂量-反应实验轨迹（dose_probe.json / dose_cb.json）的三维修度成对盲评：每个 (任务, 种子, 剂量档) 格内 cogsim 回复 vs 三档对照回复两两配对（两条措辞各配一次），gpt 评委盲评（左右顺序随机化、评委不知来源），逐维度判 A/B/平。n=100 种子/任务，共 7200 次对比；聚合按维度 × 对手 × 任务，种子聚类 bootstrap 95% CI；\* = CI 全正。

三个维度：consistency（与历史/画像/语境一致性）、appropriateness（反应分寸与输入剂量匹配）、naturalness（语言自然度/人味）。
