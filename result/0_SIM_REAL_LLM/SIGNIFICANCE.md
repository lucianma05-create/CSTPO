# 梯度反应实验

范围：证据梯度剂量-反应（esconv/p4g 显著占优）与 cb 价格让步梯度（重做版）。全部估计值带种子聚类 bootstrap 95% CI（2000 次，逐 (任务,种子) 聚类）；成对 diff = cogsim − 对照；\* = CI 不含 0。机器可读数据在 significance.json，原始数据在 dose_probe.json / dose_cb.json。

## Baseline 用户模拟器（对照阶梯）

| 档 | 实现 | 论文来源 |
|---|---|---|
| persona | 强画像扮演（角色卡 + 完整用户信息） | ESC-Eval "ESC-Eval: Evaluating Emotion Support Conversations in Large Language Models"（Zhao et al., EMNLP 2024，arXiv:2406.14952） |
| persona_resist | 强画像 + 抗轻易同意强化提示 | TRIP "Strength Lies in Differences! Improving Strategy Planning for Non-collaborative Dialogues via Diversified User Simulation"（Zhang et al., EMNLP 2024） |
| bdi | 显式 BDI 文本进提示、无转移计算 | 本项目协议设计（04 §9 对照，无文献来源） |
| cogsim | 完整 BDI+情绪+转移机制 | 本项目（被测对象） |

注：提示式三档均为本仓库 re-implemented（gpt-5.5 底座），非原作者代码。

## 设置

同一用户同一动作前快照，agent 话语按剂量四档 × 2 措辞（各档语义见下表），四档模拟器各续演一步。esconv/p4g 用**证据梯度**（L0 空话零信息 / L1 泛泛信息 / L2 针对性实质信息 / L3 针对性信息+可行方案），反应 = 态度变化评分（gpt 0-3）；cb 用**价格让步梯度**（L0 纯询问无价格 / L1 轻微还价 95% 要价 / L2 中度还价 98-99% / L3 全要价+即刻付款承诺，价格严格单调 L1<L2<L3），反应 = 卖方让步评分（gpt-5.5 0-3，judge 告知挂牌价，3 分档含"惊讶/确认→成交流程"；种子过滤租赁与已成交场景，价格锚定卖家前缀实际报价）。区分度指数 = L3 − L0。

## 配对差（cogsim − 对照）

证据梯度（esconv+p4g 合并）：指数 +0.58 [0.39,0.76]\* / +0.69 [0.53,0.85]\* / +0.60 [0.43,0.77]\*；L0 +0.24 [0.12,0.36]\* / +0.26 [0.16,0.37]\* / +0.20 [0.09,0.31]\*（全部显著为正）。

cb 价格梯度：指数 vs persona = −0.40 [−0.74,−0.07]\*；vs resist −0.17 [−0.53,0.19]；vs bdi −0.25 [−0.59,0.09]。L0 三档全无显著差（−0.03~+0.01）。曲线形态：cogsim 渐进让步（L1 起均匀上升），提示式前期死守、L3 跳变——指数奖励后者形态，cogsim 的平滑形状更接近真人讨价还价。
