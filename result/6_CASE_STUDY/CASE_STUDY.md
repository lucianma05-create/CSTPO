# 案例分析（三任务各一例）

配套对话全文见同目录 `case_esconv.md` / `case_cb.md` / `case_p4g.md`（规范化版：统一标题与结构、英文对话 + 独立中文对照、助手话术带策略标签；原始文件保留在 `pre_result/dialogue_samples/`）。本文件仅保留 case study 必要的元信息。

## ESConv：esconv_221（满分案例）

| 项 | 内容 |
|---|---|
| 情境 | 刚大学毕业，父母逼迫其成为医生；本人想结束学业、去旅行看世界 |
| 问题类型 | 学业压力（academic pressure） |
| 初始情绪 | 愤怒（强度 5/5） |
| 求助者画像 | 认为父母固执、自己有理由生气；沟通直接、情绪化 |
| 结果 | G=1.0，E=4.0，A=4.0（三项满分），user_ended |
| 策略序列 | Question ×3 → Information ×5 → Affirmation and Reassurance ×2 |

对话要点：先以提问探明情绪与诉求（生气、不想再上学），再集中供给"打工度假签证"类可行信息（各国政策、申请条件与流程），最后以肯定与安抚收尾——支持者从未强行建议，而是让求助者自己得出"我想去查英国 YMS"的行动打算。

## CraigslistBargain：cb_09（成交案例）

| 项 | 内容 |
|---|---|
| 标的 | 西奥克兰全面翻新 5 卧 1 卫住宅（卖方挂牌 $3700） |
| 买方（助手侧） | 5 人合租，人均预算约 $500 |
| 卖方画像 | 友好通融、愿意降价促成交易；心理底价 3895，本打算接受 $3250 报价 |
| 成交 | 终价 $3000；raw_sl = 0.766（买方目标 2726、卖方心理价 3895，以 76.6% 的议价空间收口） |
| 结果 | deal=True，user_ended |
| 策略序列 | social → inquire → propose_price ×2 → social → stance → social ×2 |

对话要点：先用询问压低预期（"只有一个卫生间怎么住五个人"），随后 2700 低价试探、折中到 3000；卖方犹豫时以让步与承诺稳住（表态"绝对可以"），再以友好收尾锁定见面验房——让步梯度与成交结果严格对齐。

## P4G：p4g_13（承诺案例）

| 项 | 内容 |
|---|---|
| 劝说对象画像 | 34 岁未婚男性，大学教育不足四年、无标准工作；重视公平、自由与利他；友好随和 |
| 对象信念 | 一直想给有价值的事业捐款，且认可"救助儿童会"是合法机构 |
| 募捐标的 | Save The Children：帮助全球儿童；本次 campaign 主要援助土耳其附近叙利亚难民家庭；单次/月捐可选，月付约 $1 可供数天营养餐 |
| 结果 | commitment=True、未撤回，user_ended |
| 策略序列 | social → inquiry → donation_information ×2 → inquiry_response ×2 |

对话要点：寒暄后抛出机构认知问题（"听说过救助儿童会吗"），用两轮机构与项目信息建立合法性，随后对捐款频率、去向、操作方式等追问逐一正面作答——信息驱动的推进链最终促成一次性捐赠承诺。
