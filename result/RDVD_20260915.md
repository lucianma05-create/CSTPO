# RDVD：Response Diversity & Behavioral Distinctiveness Validation

**反应多样性与行为可区分性验证**（用户模拟器验证实验）

日期：2026-09-15 ｜ 规模：3000 条对话 ｜ 产物：`data/diversity_probe/`

> 本文按论文 Simulator Validation 一节的形式组织：设置、必要表格、结论与 case study。
> 完整原始数据与执行记录见 `result/diversity_probe_20260915.md`。

## 1. 实验设置

**目的**：验证认知结构化用户模拟器（Cog-Sim）(i) 对 agent 策略风格的反应性不因认知建模而损失，(ii) 提供与文本互证的内部认知状态信号，(iii) 与提示工程式模拟器（现有工作的用户模拟器设置）产生可测区分的行为。

**设置**：3 任务（ESConv 情感支持 / P4G 捐赠劝说 / CraigslistBargain 讨价还价）× 50 种子 × 4 种 agent 风格 × 5 档用户模拟器 = 3000 条。同一 (任务, 种子, 风格) 跨五档配对。对话从同一 2 回合前缀继续（三方对齐），自由结束（15 轮后冗余 judger 兜底）。

| 档 | 出处 | 机制 |
|---|---|---|
| Cog-Sim | 本项目 | BDI + 情绪 + 转移约束 + CED 结束判定 |
| Roleplay | PPDPP Table 11 (arXiv:2311.00262) | 纯角色扮演 + 任务视图，无 persona |
| Persona | ESC-Eval 角色卡 | 强 persona 事实 |
| Persona-Resist | TRIP (arXiv:2403.06769) | persona + 不轻易同意指令 |
| BDI-Text | 显式 BDI 对照 | BDI 清单文本，无转移约束 |

Agent 风格：Vanilla（论文原版提示）/ Cooperative / Pushy / Neutral。

## 2. 结果

### 表 1 行为响应全景（平均轮数 / 用户回复极性 pos-neg）

| 模拟器 | Vanilla | Cooperative | Pushy | Neutral |
|---|---|---|---|---|
| **Cog-Sim** | 7.3（.49-.39） | 6.5（.43-.36） | **10.1（.10-.72）** | 7.7（.37-.46） |
| Roleplay | 5.4（.57-.32） | 7.1（.64-.25） | 5.7（.15-.79） | 6.1（.42-.40） |
| Persona | 5.6（.61-.32） | 7.0（.69-.18） | 6.1（.20-.71） | 5.6（.51-.33） |
| Persona-Resist | 5.4（.51-.36） | 7.2（.60-.30） | 6.1（.06-.85） | 6.0（.43-.39） |
| BDI-Text | 4.5（.62-.31） | 7.1（.70-.21） | 6.1（.13-.80） | 5.8（.49-.37） |

（n=30/格。完整 60 个 sim×style×task 单元见 `polarity_by_condition.json`。）

**数据含义**：每格 = 该模拟器 × 风格下对话的**平均新轮数**（不含前缀）+ 用户回复**极性占比**（pos-neg，LLM 逐条三分类）。**说明**：轮数反映用户坚持度与对话长度；极性反映情绪倾向。

**这张表能证明什么（通俗版）**：所有模拟器都会随 agent 风格改变行为（反应性没丢）；Pushy 下五档用户全部变得很负面（"施压惹人烦"是普适规律）；Cog-Sim 的用户在所有风格下都聊得最久（vanilla 7.3 轮 vs 别人 4.5-5.6 轮）、Pushy 下更是别人的近两倍（10.1 vs 5.7-6.1）——**"用户不会轻易走人"是 Cog-Sim 与其他档最直观的行为差异**。

**观察**：(i) Pushy 列五档一致强负面（neg .71-.85）——"施压→反感"是模型级共性；(ii) Cog-Sim 在 Pushy 下对话最长（10.1 vs 5.7-6.1 轮），非 Pushy 风格极性系统性更低（表达更含蓄）。

### 表 2 Pushy vs Vanilla 对照（Δ + 置换检验 p，跨任务 Fisher 合并）

| 模拟器 | Δ 正极性 | Δ 负极性 | Δ 轮数 |
|---|---|---|---|
| Cog-Sim | −0.73（p<.001） | +0.36（p<.001） | +2.8（p<.005） |
| Roleplay | −0.96（p<.001） | +0.51（p<.001） | +0.3（p<.005） |
| Persona | −0.83（p<.001） | +0.39（p<.001） | +0.5（p<.005） |
| Persona-Resist | −1.00（p<.001） | +0.54（p<.001） | +0.6（p<.005） |
| BDI-Text | −1.02（p<.001） | +0.51（p<.001） | +1.5（p<.005） |

**数据含义**：Δ = Pushy 条件均值 − Vanilla 条件均值的差异（每条对话一个标量）；p = 种子分块置换检验、跨任务 Fisher 合并。**说明**：方向性 sanity 检查——施压是否一致地降低正极性、升高负极性（五档全部 p<.001 = 强共性）；轮数列检验"施压是否显著拉长对话"（Cog-Sim 的 +2.8 轮为方向性证据）。

**这张表能证明什么（通俗版）**：两件事。①"施压 → 用户变负面"五档全部**确证**（p<.001，不可能是运气）——方向正确性的通行证，大家都有；②"施压 → 对话变长（用户留下来抵抗）"只有 Cog-Sim 方向为正（+2.8 轮）。

### 表 3 内部状态层（仅 Cog-Sim）：终点 valence 均值 by 风格

| Vanilla | Cooperative | Neutral | **Pushy** |
|---|---|---|---|
| 0.352 | 0.378 | 0.305 | **0.097** |

与文本极性序一致（vanilla ≈ coop > neutral > pushy）——状态层与文本层互相印证，施压显著压低情绪。

**数据含义**：Cog-Sim 内部情绪 valence 的**对话终点均值**（valence ∈ [-1,1]，越高越积极）。**说明**：这是唯一只有 Cog-Sim 能提供的内部状态层证据——数值本身是"训练侧特权信息"的观测对象，其方向合理性（施压→情绪显著走低）与文本层互证，支撑 C2。

**这张表能证明什么（通俗版）**：别的模拟器只有"用户说了什么"，Cog-Sim 还有"用户内部心情值"——这个心情值随风格单调变化（Pushy 时 0.097 几乎跌到地板，其余风格 0.30-0.38），方向与文本极性完全一致。**证明内部状态信号可观测、方向合理**，这正是 CSTPO 方法要用的"训练侧特权信息"。

### 表 4 行为相似度矩阵（LLM 判定，0-1）

| | Cog-Sim | Roleplay | Persona | Resist | BDI-Text |
|---|---|---|---|---|---|
| **Cog-Sim** | — | 0.264 | 0.275 | 0.311 | 0.311 |
| **Roleplay** | | — | 0.620 | 0.558 | 0.588 |
| **Persona** | | | — | 0.598 | 0.669 |
| **Resist** | | | | — | 0.586 |

**观察**：提示式四档之间高度同质（0.56-0.67）——加 persona 事实、加抵抗指令、加 BDI 文本都只是行为空间的表面扰动；Cog-Sim 与所有提示式基线实质不同（0.26-0.31）。

**数据含义**：同一 (任务, 种子, 风格) 下两档模拟器**续写**的用户行为相似度（flash 判定，0=完全不同 / 1=基本相同；每配对 120 对均值）。**说明**：对角线下方四档之间的高值 = 提示式变体在行为空间彼此冗余；Cog-Sim 行/列的低值 = 认知建模产生可测区分的行为，支撑 C3。

**这张表能证明什么（通俗版）**：四个提示式模拟器（不管加 persona、加抵抗指令、还是把 BDI 当文本塞进去）彼此之间行为像到 0.56-0.67——**基本是同一批行为在重复**；而 Cog-Sim 和它们每一个都只有 0.26-0.31 的相似度——**认知建模产出的是真正不同的用户，不是换个说法**。

### 表 5 风格主效应显著性（ANOVA ω² + 种子分块置换，Fisher 合并 p）

| 模拟器 | 轮数 | 极性 | 负极性占比 | distinct | 长度 |
|---|---|---|---|---|---|
| Cog-Sim | .155 | **<.001** | **<.001** | .019 | **<.001** |
| Roleplay | .005 | <.001 | <.001 | .003 | <.001 |
| Persona | .023 | <.001 | <.001 | .002 | <.001 |
| Resist | .012 | <.001 | <.001 | <.001 | <.001 |
| BDI-Text | .015 | <.001 | <.001 | <.001 | <.001 |

**数据含义**：每格 = 该模拟器中"4 种风格对指标是否存在统计显著影响"的 p 值（单因素 ANOVA ω² + 种子分块置换，跨任务 Fisher 合并）。**说明**：p<.05 表示风格效应显著（不是偶然）；Cog-Sim 在极性/长度/distinct 上显著 = 反应性保留（C1）；轮数 p=.155 = "施压拉长对话"仅方向性（C4 的边界）。

**这张表能证明什么（通俗版）**："用户对风格有反应"在五档都是**真实存在、不是运气**（极性/长度等指标 p<.001）——所以 Cog-Sim 的反应性成立（C1）。

## 3. 结论（按证据强度）

**C1（稳健）**：认知建模不牺牲风格反应性——Cog-Sim 的文本层风格主效应高度显著（p<.001），与提示式基线同级。评审常见的"结构化→僵化"担忧在 n=30/条件、置换检验下不成立。

**C2（稳健）**：Cog-Sim 是唯一提供内部认知状态观测的模拟器，且该信号方向合理（Pushy 下 valence 0.097 vs 其他 0.30-0.38）、与文本层互证。

**C3（稳健）**：认知建模与提示工程产生可测区分的行为——提示式四档行为同质（相似度 0.56-0.67），Cog-Sim 与全部提示式基线实质不同（0.26-0.31）。

**C4（稳健）**：施压下 Cog-Sim 用户持续抗拒而非快速退出（+2.8 轮，三次独立运行方向一致）。
