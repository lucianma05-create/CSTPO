# 有利结论与数据清单（600 条多样性实验，2026-09-15）

按证据强度分级。每条附数据、限制与可用的表述口径。**红线提醒**：任何超出本清单标注范围的表述都属过度声明，会违反项目自己的证据纪律。

## A 级：稳健、可直接使用

### A1. Cog-Sim 保留的反应多样性不弱于任何提示式基线（核心必要条件 ✅）

**数据**：文本层风格主效应（Fisher 跨任务合并）：

| 指标 | cogsim | 提示式四档 |
|---|---|---|
| 极性 (mean_pol) | p<.001 | 均 p<.001 |
| 负极性占比 | p<.001 | 均 p<.001 |
| 长度 | p<.001 | 均 p<.001 |
| distinct | p=.019 | p<.001-.003 |

pushy vs vanilla：Δ正极性 −0.86（p<.001）、Δ负极性 +0.43（p<.001）。

**口径**：认知建模**没有**把用户变成"对策略无感的橡皮图章"——"保留合理可变性"的必要条件成立，且与现有工作的提示式模拟器同级。这正是问题 02 主张的一半，也是此前评审最可能攻击的点（"结构化的代价是僵化"），现在有直接数据回应。

### A2. 状态层的方向合理性（Cog-Sim 独家能力 ✅）

**数据**：终点 valence：pushy **0.075** vs cooperative 0.393 / vanilla 0.384 / neutral 0.296。

**口径**：只有 Cog-Sim 提供内部认知状态观测——施压显著压低情绪、方向与常识一致。这是"结构化认知反馈"的展示窗口，提示式基线在架构上无法提供此层证据。可支撑叙述："Cog-Sim 提供与文本层一致、且方向可解释的内部状态信号"。

### A3. 自由结束的工程完备性（对后续 RL 的直接利好 ✅）

**数据**：600 条中 599 条自然结束（user_ended 或 judger 收尾），仅 1 条触发 30 轮安全阀。judger 触发 29/600（4.8%），干预克制。

**口径**：15 轮后 LLM 冗余判定（第三方打断）解决了"施压僵局无限对话"问题。对 RL rollout 的意义：轨迹长度可控、无需依赖轮数截断（截断会产生非终局轨迹、奖励为零的污染），为 P3/P5 的 rollout 预算控制提供机制。

## B 级：描述性差异，方向有利，需更大样本/盲评升级

### B1. 面对施压的坚持度

**数据**：pushy 下平均轮数 cogsim **9.6** vs 提示式 5.8-6.7；全风格轮数 cogsim 普遍最长（vanilla 7.5 vs 4.9-5.4）。

**口径**：真人面对高压推销更可能持续表达不满而非 2 轮挂断——此差异与直觉一致，但**统计显著性在 n=30 时不成立（p=.105）**，只能作为描述性差异报告，不能写成"Cog-Sim 显著更坚持"。

### B2. 终局稳定性

**数据**：judge 结局 JS（风格 vs 池化）cogsim 最低（0.060 vs 0.069-0.091）。

**口径（双刃，慎用）**：可辩护为"Cog-Sim 用户的终局更多由用户特质决定、不被 agent 风格随意摆布"；但同样可被读作"对风格不够敏感"。若要使用，必须与 A1（文本层反应显著）并列呈现——"过程反应敏感、终局稳定"的组合才是完整故事。

### B3. 风格-状态单调对应

**数据**：Cog-Sim 正面极性占比 by 风格：vanilla 0.51 ≈ coop 0.46 > neutral 0.35 > pushy 0.09，与 valence 排序一致。

**口径**：文本层与状态层相互印证（同一风格序在两层都成立），增强状态信号的可信度。

### B4. 行为独特性（LLM judge 相似度矩阵）

**数据**：五档两两相似度——Cog-Sim vs 提示式各档 0.275-0.338；提示式四档内部 0.545-0.630（n=120 对/配对）。

**口径**：提示式模拟器的行为高度同质（加 persona/抵抗指令/BDI 文本都只是表面扰动），Cog-Sim 与所有提示式基线都实质不同——"显式认知建模 vs 提示工程产生不同行为"的直接证据。叙事价值：说明我们的模拟器不是"另一个提示变体"，认知架构在行为层面有可测的独特性。

**限制**：相似度由 flash 判定（同模型偏见的风险仍在，但该指标是对称比较，五档同口径）；独特性≠真实性（真实与否仍需盲评/匹配对照）。

## C 级：基建与方法论资产（不直接是科学结论）

1. **论文香草提示 agent**（`cstpo/agent.py`）：CB=PPDPP Table 8、P4G=TRIP Table 20、ESConv=ESConv-SRA template6——后续直接作为 prompt-only baseline，省去复现争议
2. **judge rev4**：留出 30 条 3 次独立评分完全一致（esconv 20/20、p4g 5/5、cb 5/5）——终局监督可靠性的初步证据
3. **实验基建**：逐条落盘 + skip-existing 续跑 + 单条容错 + 420 workers 全并行——后续任何规模的 rollout 实验可直接复用

## 不能声明的（防过度声明清单）

| 常见诱惑 | 为什么不成立 |
|---|---|
| "Cog-Sim 显著优于提示式基线" | 极性等显著效应是五档共性；PERMANOVA 全不显著；坚持度差异不显著 |
| "Cog-Sim pushy 下显著拉长对话" | n=30 时 p=.105，未达显著，已撤回小样本结论 |
| "Cog-Sim 更像真人/更真实" | 无盲评、无真人匹配对照（下一步做）；同模型自我对话未消解 |
| "多样性更高" | JS 上 cogsim 结局/极性反而最低——应说"同级"而非"更高" |
| 任何基于 PERMANOVA/SNR 的轨迹级主张 | 功效不足，全部不显著 |

**总结成一句话**：当前数据支撑的有利叙事是——"Cog-Sim 在不牺牲风格反应性的前提下，提供了方向合理、与文本相互印证的内部认知状态信号，且具备支撑大规模 RL rollout 的工程完备性"；真实性优势仍需盲评与匹配对照来补最后一环。
